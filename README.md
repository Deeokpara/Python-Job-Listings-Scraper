Automated Python Job Listings Scraper

Project Overview
A Python project that scrapes job listings, cleans the data,
stores it in a database, and visualizes insights with Streamlit.

 Technologies
- Python
- BeautifulSoup
- Pandas
- Streamlit
- SQLite
- SQLAlchemy

Features
- Web scraping
- Data cleaning
- Database storage
- Dashboard analytics

How to Run
python scraper/scraper.py
streamlit run dashboard/app.py Automated Python Job Listings Scraper
